# Turtle Cross

This project is a Python game built using the Turtle graphics library. The objective of the game is to control a turtle character and help it cross the screen while avoiding obstacles. Turtle Cross is a great example for beginners learning about Python's Turtle module, game loops, collision detection, and simple animation.

## Features

- Interactive gameplay with keyboard controls
- Randomly generated obstacles
- Simple collision detection
- Score tracking 
- Beginner-friendly code structure

## How to Run

1. Ensure Python (version 3.x) is installed.
2. Confirm that the 'turtle' module is available.
3. Navigate to the 'Python/Turtle Cross' directory.
4. Execute the main script:
   bash   python turtle_cross.py
   

## Gameplay

- Use the arrow keys to control the turtle's movement'
- Avoid obstacles that move across the screen.
- Successfully cross to the other side to win points or advance levels.

## Example

Turtle starts at the bottom of the screen.
Obstacles move horizontally.
Player uses arrow keys to move turtle up, left, or right.
If turtle collides with obstacle, the game ends.
