Rock Paper Scissor

This project is a simple implementation of the classic Rock Paper Scissor game using Python. The game allows a user to play against the computer, making choices between Rock, Paper, or Scissor, with the winner determined according to standard rules.

Game Rules

- Rock beats Scissor
- Scissor beats Paper
- Paper beats Rock
- If both are same then its a draw

Features

- Interactive command-line gameplay
- Computer opponent with random choices
- Score tracking for multiple rounds
- Clear instructions and input validation

How to Run

1. Make sure you have Python installed (version 3.x recommended).
2. Navigate to the `Python/Rock Paper Scissor` directory.
3. Run the game script:
   ```bash
   python rock_paper_scissor.py
